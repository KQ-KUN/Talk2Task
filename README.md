# Talk2Task

自动提取群聊内容，整理出待办事项、负责人、时间和风险，并添加到备忘录。

---

## 项目简介

Talk2Task 是一个面向办公协同场景的轻量工具。  
它不要求员工学习复杂功能，也不要求手动整理群聊内容，而是直接完成三件事：

1. 自动提取群聊内容  
2. 自动整理待办事项、讨论摘要和风险提醒  
3. 一键添加到备忘录  

项目目标不是做一个功能堆叠的平台，而是做一个员工打开就会用、几乎不需要学习成本的协同助手。

---

## 核心流程

### 1. 自动提取群聊内容
系统自动获取最近同步的群聊内容，无需手动复制粘贴。

### 2. 自动整理任务
基于群聊内容自动提炼：
- 讨论摘要
- 待办事项
- 负责人
- 截止时间
- 风险提醒

### 3. 添加到备忘录
将整理结果直接沉淀到备忘录，方便后续查看和继续推进。

---

## 核心功能

### 1. 群聊内容提取
用户点击一次按钮，即可获取最近同步的群聊内容。

### 2. 任务自动整理
系统自动将聊天内容转化为结构化待办事项。

### 3. 风险提醒
自动标记讨论中的依赖、阻塞和延期风险。

### 4. 任务状态管理
支持将待办事项标记为：
- 待开始
- 进行中
- 已完成

### 5. 备忘录沉淀
整理后的结果可以直接添加到备忘录中，形成后续查看依据。
